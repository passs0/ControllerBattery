# LifeBar Release Notes

## v1.1.1 — Quality-of-life update

- Replaced decorative controller cards with compact rows and capped the popover's device-list height.
- Collapsed settings by default so connected controllers remain the focus.
- Improved control labels and threshold-slider accessibility.
- Removed the duplicate legacy icon from release bundles while retaining all four dynamic appearances; stripped nonessential binary symbols.
- Built and ad-hoc code-signed the release through GitHub Actions.

The app bundle is approximately 1.9 MB; the DMG is approximately 2.3 MB.
